# OctoPus-Samples
OctoPus samples of input, output, and images for transcribing.

### Folders

- Images: JianPu image downloaded for transcribing test
- External-Trans: JPS transcriptions for files in Images; each may be transcribed manually by a
  person or generated by an AI/LLM.
- Input-JPS: Sample JPS input files
- Output-JPG: Rendered JPEG files from sources in Input-JPS
- Output-PDF: Rendered PDF files from sources in Input-JPS
- Output-PNG: Rendered PNG files from sources in Input-JPS
- Output-SVG: Rendered SVG files from sources in Input-JPS
